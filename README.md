# job_scraper

A comprehensive job scraping tool that collects job listings from multiple portals including LinkedIn, Naukri.com, TimesJobs, Foundit, and Glassdoor.

## Features

- **Multi-portal Support**: Scrape jobs from 5 popular job sites
- **Unified Output**: Standardized job data across all sources
- **Flexible Export**: Save to Excel or Google Sheets
- **Automated Scheduling**: Run via GitHub Actions on a schedule
- **Robust Error Handling**: Graceful handling of site changes and failures
- **Configurable**: Extensive command-line options
